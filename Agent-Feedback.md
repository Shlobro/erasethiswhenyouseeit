# Agent Feedback

Agents add notes here for the user to review. Each note is something an agent thinks every
future agent should know. The user decides which notes become rules in `AGENTS.md`.

Rules for this file:

- Add new entries at the **end** only.
- Never edit or delete an existing entry.
- One entry per finding.

Entry format:

```markdown
### YYYY-MM-DD: <short title>
- **Branch / PR:** <branch-name> / <PR link if known>
- **What I saw:** <the fact, with file paths or commands>
- **Why it matters:** <what goes wrong if agents don't know this>
- **How I know:** <verified in code / ran it / read in docs / suspected, not verified>
- **Suggested AGENTS.md line:** <one sentence, ready to paste>
```
